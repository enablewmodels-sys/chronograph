# Shared API contract

`openapi.json` is generated by the Rust server's `export_openapi` example. Its request definitions are shared with MCP; the connector catalog is embedded as a vendor extension. It is OpenAPI 3.1 / JSON Schema 2020-12. Responses intentionally remain extensible objects rather than claiming complete generated DTOs.

Use `cargo run --locked -q -p chronograph-server --example export_openapi > sdk/schema/openapi.json` from the repository root. `scripts/sdk/verify-contract.py` validates the format and detects drift. Exact integer ranges and cross-field constraints (tensor byte lengths, binding rules, timestamp intervals, clock domains and sequential checkpoints) are enforced by the server in addition to JSON Schema.

Graph IDs/revisions and time values are strings. This preserves 64-bit values across JavaScript and other runtimes. Source licensing is the same PolyForm Perimeter 1.0.0 license as the repository.
